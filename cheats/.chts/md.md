### tips, tricks

## basics
| item                     |syntax                         |
| :____                    |:___                           |
| headings                 | 1-6 # then <sp> then text     |
| horiz line               | 3 ---                         |
| break                    | empty line                    |
| italic text              | * or _ before and after       |
| bold text                | ** or __ before and after     |
| bold+italic              | *** or ___ before and after   |
| mix and match            | change b/a on between text    |
| strikethrough            | ~~ before and after           |
| ordered list             | 1. before each item           |
| unordered list           | -<sp> before each item        |
| inline code              | ` before and after            |
| fenced code blk          | ``` before and after          |
|    site lang             | lang or abbrv after ```       |
| block quote              | > before each line            |
| block within             | > > before line within        |
| hyperlinks               | []() for tag then link        |
| ref links                | [<ref>]: <https://...>        |
|   opt clarify text below |  "<text>"                     |
| image                    | [<alt txt>](<img loc>)        |
| turn img into link       | [![<alt txt>](<loc>)](<http>) |
