## i3 keybinds

| Keys          | Description                          |
|:---           |:---                                  |
| startx i3     | Start i3 from terminal               |
| $mod+<CR>     | Open a terminal                      |
| $mod+b        | Open chrome browser                  |
| $mod+z        | Open zim wiki                        |
| $mod+d        | Open rofi - drun mode                |
| $mod+<tb>     | Open rofi - window mode              |
| $mod+D        | Open rofi - run mode                 |
| $mod+r        | Enter or leave resize mode           |
| $mod+E        | Exit i3                              |
| $mod+R        | Restart i3                           |
| $mod+C        | Reload config                        |
| $mod+Q        | Kill window (normal close most apps) |
| $mod+w        | Tabbed layout                        |
| $mod+s        | Stacked layout                       |
| $mod+i        | Horizontal split ( | )               |
| $mod+u        | Vertical split ( -- )                |
| $mod+e        | Switch between vert. & horiz. layout | 
| $mod+f        | Toggle full-screen                   |
| $mod+<hjkl>   | Focus on window that direction       |
| $mod+<arr>    | Focus on window that direction       |
| $mod+<S-hjkl> | Move window that direction           |
| $mod+<S-arr>  | Move window that direction           |
| $mod+<#>      | Go to $ws<#0-9>                      |
| $mod+<S-#>    | Move window to $ws<#0-9>             |
| $mod+<sp>     | Toggle focus mode                    |
| $mod+<S-sp>   | Toggle floating window               |
| $mod+a        | Go to parent window                  |
