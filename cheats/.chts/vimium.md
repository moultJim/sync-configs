## cmds
| Keys | Description                      |
|:---  |:---                              |
| ?    | Help dialog for keys             |
| hjkl | Scroll ldur                      |
| gg,G | Top, bottom of page              |
| d,u  | Down, up 1/2 page                |
| f,F  | Open link current, new tab       |
| r    | Reload                           |
| gs   | View source                      |
| i    | Enter insert mode; <esc> to exit |
| yy   | Copy current url to clipboard    |
| yf   | Copy link url to clipboard       |
| gf   | Cycle forward to next frame      |
| o,O  | Open URL, bmark, or hist curr, new tab |
| b,B  | Open bookmark current, new tab   |
| /    | Find {pat} -- <cr> or <esc> |
| n,N  | Cycle fwd, bk thru matches |
| H,L  | Bk, Fwd in history |
| gi   | Focus input box |
| gu   | Up one level URL hierarchy |
| J,K  | One tab left, right |
| t    | Create new tab |
| x,X  | Close, reopen tab |
